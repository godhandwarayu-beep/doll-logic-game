# ภารกิจตุ๊กตาแม่ลูกดก 🪆

เกมฝึกคิดเชิงคำนวณ (Computational Thinking) สำหรับนักเรียนประถม
นักเรียนลากบล็อกคำสั่งแบบ Scratch พาตัวละครไปเก็บตุ๊กตาจากตัวเล็กที่สุดไปตัวใหญ่ที่สุด

**เล่นเกม:** https://godhandwarayu-beep.github.io/doll-logic-game/

## เนื้อหา 10 ด่าน
ลำดับขั้นตอน → ทิศทาง → ตรรกะการเรียงลำดับ → การทำซ้ำ (Loop) → หารูปแบบ → วางแผน → ลูปซ้อน (Nested Loop)

## การบันทึกคะแนน
- `Code.gs` คือ Google Apps Script สำหรับบันทึกคะแนนลง Google Sheets (ด่าน ดาว จำนวนครั้งที่ลอง เวลา) และส่งข้อมูลหน้าอันดับคะแนน
- Deploy เป็นเว็บแอป (เรียกใช้ในฐานะ: ฉัน, ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน) แล้วนำ URL `/exec` ไปใส่ที่ `API_URL` ใน `index.html`
- รันฟังก์ชัน `buildSummary` เพื่อสร้างแผ่นงานสรุปคะแนนรายคน
